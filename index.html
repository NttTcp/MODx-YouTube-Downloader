Frequently asked questions

Is YTMP3 Pro really free?

Yes. The web converter and the public API are both free with no account required.

What quality can I download?

Audio: 128/192/256/320 kbps MP3. Video: up to 4K (2160p) if available on the source.

Why is my download slow sometimes?

High-resolution MP4 requires downloading video and audio separately, then merging with FFmpeg. A 4K video may take a minute or two.

Do you store my downloads?

No. Files are written to a temp folder, streamed to you, and auto-deleted after 10 minutes.

Can I use this in my Discord/Telegram bot?

Absolutely — that's what the API section below is for. One GET request returns the media file directly.

Developer API

One GET request. No key, no auth, no SDK. Perfect for bots.

GET /api/mp3?url={youtube_url}&quality=320
Returns .mp3. Quality: 128, 192, 256, 320.
GET /api/mp4?url={youtube_url}&quality=1080
Returns .mp4. Quality: 360–2160 or best.
GET /api/info?url={youtube_url}
JSON metadata: title, thumbnail, duration, resolutions.
GET /api/health
Status check.
